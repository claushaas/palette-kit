# Palette Kit v0.4 — Cookbook

## Patterns & Recipes

## 1. Solid Button (Primary Action)

### Scenario

A prominent button on a surface, with text and subtle border.

### Surface (Button Fill)

```ts
const buttonFill = palette.resolve({
  usage: "fill",
  intent: "brand",
  level: 4
})
```

### Why

- `fill` → surface
- `brand` → semantic meaning
- `level: 4` → elevated but not dominant

---

### Text (Label)

```ts
const buttonText = palette.resolve({
  usage: "visualVocabulary",
  intent: "brand",
  relation: { type: "on", target: buttonFill }
})
```

### Why

- contrast explicitly enforced
- same hue, adjusted L
- no alpha

---

### Border (Optional)

```ts
const buttonBorder = palette.resolve({
  usage: "lines",
  intent: "brand",
  level: 3,
  relation: { type: "on", target: buttonFill }
})
```

## Anti‑Patterns (Do Not Do This)

- ❌ Encoding state in intent
- ❌ Using alpha for text
- ❌ Skipping relation:on for readable content
- ❌ Using overlays for branding
- ❌ Using level with visualVocabulary
