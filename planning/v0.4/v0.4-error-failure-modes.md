# Palette Kit v0.4 — Error & Failure Modes

## Purpose

This document defines **how Palette Kit fails**.

Failure is a first-class design concern.
This contract ensures that when something goes wrong:

- the failure is explicit
- the cause is understandable
- the responsibility is clear
- no silent degradation occurs

This document is about **developer experience under error**.

---

## Core Principle

> **Palette Kit never guesses, never degrades silently, and never hides errors.**

If the resolver cannot produce a correct result, it must fail.

---

## Error Categories

Palette Kit errors fall into four categories:

1. Configuration errors
2. Resolver input errors
3. Resolution failures
4. Serialization failures

Each category has different guarantees.

---

## 1. Configuration Errors

Configuration errors happen at **palette creation time**.

### Unknown Intent Registration

### Cause

- An intent is referenced in resolver but not declared in the Intent Registry

### Behavior

- Hard failure
- Throws immediately

### Example

```ts
palette.resolve({
  usage: "fill",
  intent: "refund",
  level: 3
})
```

### Error

```txt
Unknown intent "refund".
Did you forget to register it in the Intent Registry?
```

---

### Invalid Intent Definition

### Cause

- Hue or chroma out of valid range

### Behavior

- Fail during palette creation

### Reason

- Prevents corrupt semantic base

---

## 2. Resolver Input Errors

These occur when calling `palette.resolve()` with invalid combinations.

---

### Missing Required Axis

### Cause

- Required axis omitted (e.g. `level` for `fill`)

### Behavior

- Hard failure

### Example

```ts
palette.resolve({
  usage: "fill",
  intent: "brand"
})
```

---

### Forbidden Axis Combination

### Cause

- Axis used where explicitly forbidden

Examples:

- `level` with `visualVocabulary`
- `on` with `overlays`

### Behavior

- Hard failure with explanation

---

### Invalid Relation Target

### Cause

- `on` / `over` / `under` target is not a Palette Kit color output
- target belongs to incompatible usage

### Behavior

- Hard failure

---

## 3. Resolution Failures

Resolution failures happen **after validation**, during computation.

---

### Contrast Not Satisfiable

### Cause

- `on` requested
- contrast target cannot be met without violating invariants

Examples:

- extreme chroma
- insufficient luminance range

### Behavior

- Configurable:
  - throw error (default)
  - emit warning and return best effort

### Never

- silently reduce contrast

---

### Out-of-Gamut Resolution

### Cause

- resolved OKLCH color cannot be represented in requested output space

### Behavior

- Depends on output strategy:
  - clamp
  - fallback
  - throw

Must be explicit in config.
If a default is provided, it should be explicit (commonly clamp with a warning),
to preserve a resolvable output.

---

## 4. Serialization Failures

Serialization failures happen **after resolution**.

---

### Unsupported Output Format

### Cause

- requested output format not implemented

### Behavior

- Hard failure

---

### Precision Loss Beyond Threshold

### Cause

- conversion introduces unacceptable error

### Behavior

- Optional warning
- never silent

---

## Warning vs Error Policy

Palette Kit distinguishes:

| Condition | Default |
| --- | --- |
| Invalid usage | Error |
| Missing axis | Error |
| Unsatisfiable contrast | Error |
| Gamut clipping | Warning |
| Precision loss | Warning |

This policy is configurable but defaults are strict.

---

## Developer Responsibility Boundary

Palette Kit guarantees:

- correctness within declared constraints
- explicit failure otherwise

Palette Kit does NOT guarantee:

- design correctness
- aesthetic quality
- accessibility without declaration

---

## Why This Matters

Silent failures:

- rot systems
- create false trust
- surface late in UI

Explicit failures:

- teach correct usage
- prevent semantic drift
- scale teams safely

---

## Summary

- Errors are intentional
- Failures are explicit
- No heuristics, no guessing
- Resolver correctness > convenience

This document defines the **Error & Failure Modes Contract**
for Palette Kit v0.4.
