# Palette Kit v0.4 — Official Resolver Presets

## Purpose

This document defines the **official resolver presets** provided by Palette Kit v0.4.

Presets are curated configurations that adjust **magnitude and feel**
while preserving the full semantic and architectural contract of the system.

Presets do not change how the resolver works.
They only change **how strong its effects feel**.

---

## Preset Philosophy

- Presets are **opinions**, not requirements
- All presets are implemented via `ResolverConfig`
- Presets are safe, documented, and reversible
- Users can start with a preset and customize further

---

## Available Presets

### 1. Soft

**Intent**

- Calm, subtle, low‑contrast UI
- Content‑first products
- Reading‑heavy applications

**Characteristics**

- Smaller state deltas
- Flatter level curves
- Softer overlays and shadows

```ts
preset: "soft"
```

**Typical Uses**

- Editorial sites
- Knowledge tools
- Productivity apps

---

### 2. Neutral (Default)

**Intent**

- Balanced, modern UI
- General‑purpose applications
- Matches current design system norms

**Characteristics**

- Radix‑like level curves
- Moderate state deltas
- Clear but non‑aggressive contrast

```ts
preset: "neutral"
```

**Typical Uses**

- SaaS dashboards
- Internal tools
- Consumer apps

---

### 3. Strong

**Intent**

- High energy, high feedback
- Interaction‑heavy products
- Brand‑driven experiences

**Characteristics**

- Steeper level curves
- Larger state deltas
- Strong overlays and shadows

```ts
preset: "strong"
```

**Typical Uses**

- Consumer apps
- Gaming‑adjacent UIs
- Marketing‑driven products

---

## Preset Comparison

| Property | Soft | Neutral | Strong |
| ------ | ------ | -------- | -------- |
| Level contrast | Low | Medium | High |
| State deltas | Small | Medium | Large |
| Overlay alpha | Subtle | Balanced | Prominent |
| Shadow depth | Light | Normal | Deep |

---

## Using Presets

```ts
const palette = createPaletteKit({
  context: "light",
  preset: "neutral"
})
```

Presets internally map to predefined `ResolverConfig` objects.

---

## Customizing Beyond Presets

Presets can be combined with overrides by starting from the complete
`ResolverConfig` mapped from that preset:

```ts
createPaletteKit({
  preset: "soft",
  resolverConfig: {
    ...softResolverConfig,
    stateDeltas: {
      ...softResolverConfig.stateDeltas,
      luminance: {
        ...softResolverConfig.stateDeltas.luminance,
        hover: 0.05
      }
    }
  }
})
```

---

## Guarantees

All presets guarantee:

- no semantic changes
- no contrast violations
- deterministic output
- compatibility with all usages

---

## Summary

Presets exist to:

- accelerate adoption
- provide safe defaults
- encode proven perceptual profiles

They are **starting points**, not constraints.
