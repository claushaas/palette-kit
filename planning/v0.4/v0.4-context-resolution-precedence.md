# Palette Kit v0.4 — Context Resolution & Precedence

## Purpose

This document formalizes how **context** (e.g. `light`, `dark`) is defined, resolved,
and overridden in Palette Kit v0.4.

The goal is to ensure that environmental context is:

- explicit
- predictable
- overrideable by conscious decision
- never inferred implicitly

Context is treated as an **environmental axis**, not a semantic one.

---

## Definition of Context

`context` represents the **physical luminance environment** in which colors are resolved.

It affects:

- interpretation of luminance (L)
- contrast thresholds
- perceptual curves
- directionality of contrast resolution

It does **not** affect:

- semantic intent
- usage
- level
- relation
- state

Context answers the question:

> **In what luminance environment is this color being resolved?**

---

## Context as an Environmental Default

Context is defined at **Palette Kit creation time** as a default environment.

```ts
const palette = createPaletteKit({
  context: "light",
  preset: "neutral",
  resolverConfig: defaultResolverConfig
})
```

This context becomes the **ambient default** for all subsequent resolver calls
made through this palette instance.

No resolver is required to explicitly specify context in the common case.

---

## Resolver-Level Context Override

Individual resolver calls may **explicitly override** the ambient context.

```ts
palette.resolve({
  usage: "fill",
  intent: "neutral",
  level: 2,
  context: "dark"
})
```

This override means:

> “Resolve this color as if it were in a dark environment,
> regardless of the palette default.”

This is a conscious, local decision.

---

## Precedence Rules

Context resolution follows a strict and simple precedence order:

1. **Resolver-level context** (highest priority)
2. **Palette-level context**
3. **System defaults** (fallback)

```ts
effectiveContext =
  resolver.context
  ?? palette.context
  ?? systemDefaultContext
```

No additional heuristics or inference are applied.

`systemDefaultContext` is provided by the host environment
and injected by the developer. Palette Kit never reads it implicitly.

---

## Runtime Configuration Safety

Context configuration is **runtime-safe** under the following constraints:

- `createPaletteKit` is pure
- palette instances are immutable
- changing context requires creating a new instance

```ts
const lightPalette = createPaletteKit({ context: "light" })
const darkPalette = createPaletteKit({ context: "dark" })
```

No global mutable state is allowed.

---

## Typing Model

Context is optional at the resolver level.

```ts
type ResolveOptions = {
  usage: Usage
  intent: Intent
  level?: Level
  on?: RelationTarget
  over?: RelationTarget
  under?: RelationTarget
  state?: State
  context?: Context // optional override
  output?: ColorOutput
}
```

`RelationTarget` is any output returned by a previous Palette Kit resolve call.
Serialized targets are normalized back to OKLCH before relation logic.

This ensures:

- minimal boilerplate
- explicit overrides
- strong DX

---

## What Context Never Does

Context must never:

- infer semantic intent
- override declared relations (`on | over | under`)
- modify level or state
- introduce implicit behavior
- be auto-detected from environment

---

## Why This Model Exists

Without explicit context resolution:

- dark/light behavior becomes implicit
- resolver behavior becomes surprising
- code reviews lose clarity
- debugging becomes non-deterministic

This model guarantees:

- explainable behavior
- predictable resolution
- explicit environmental control

---

## Example Flow

```ts
const palette = createPaletteKit({
  context: "light"
})

const surface = palette.resolve({
  usage: "fill",
  intent: "neutral",
  level: 1
}) // resolved in light context

const previewSurface = palette.resolve({
  usage: "fill",
  intent: "neutral",
  level: 1,
  context: "dark"
}) // resolved in dark context
```

Both calls are valid, explicit, and deterministic.

---

## Summary

Context in Palette Kit v0.4 is:

- environmental, not semantic
- globally defined, locally overrideable
- explicit, never inferred
- deterministic and auditable

This document defines the **Context Resolution & Precedence contract**
for Palette Kit v0.4.
