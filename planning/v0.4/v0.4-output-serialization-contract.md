# Palette Kit v0.4 — Output & Serialization Contract

## Purpose

This document defines how Palette Kit delivers resolved colors to consumers.

It formalizes the separation between:

- **color resolution** (perceptual, semantic, deterministic)
- **color serialization** (formatting for consumption)

Serialization is not part of color semantics.
It is a delivery concern.

---

## Core Principle

> Palette Kit always resolves colors in a canonical perceptual space.  
> Output format is applied *after* resolution.

Resolver ≠ Serializer.

---

## Canonical Color Space

- Internal canonical space: **OKLCH (via OKLab)**
- All semantic decisions occur here
- No resolver logic depends on output format

---

## Output Formats

```ts
type ColorOutput =
  | "oklch"
  | "oklab"
  | "srgb"
  | "p3"
  | "hex"
  | "rgba"
```

These formats exist solely for delivery.

---

## Output Configuration

### Palette-level default

```ts
const palette = createPaletteKit({
  context: "light",
  output: "rgba"
})
```

All resolved colors are serialized as RGBA.

---

### Resolver-level override

```ts
palette.resolve({
  usage: "fill",
  intent: "brand",
  level: 4,
  output: "hex"
})
```

---

## Output Precedence

1. Resolver-level `output`
2. Palette-level `output`
3. System default (`oklch`)

No inference.

---

## Typed Outputs

```ts
type OutputMap = {
  oklch: OKLCH
  oklab: OKLab
  srgb: RGB
  p3: RGB
  hex: string
  rgba: { r: number; g: number; b: number; a: number }
}
```

```ts
function resolve<O extends ColorOutput>(
  options: ResolveOptions & { output?: O }
): OutputMap[O]
```

---

## Serialization Rules

Serializers:

- never alter hue, chroma, or luminance
- never apply contrast logic
- never apply fallbacks
- are pure functions

---

## Platform Notes

### React Native

- Recommended output: `rgba`
- No OKLCH leakage
- Direct compatibility with RN styles

### Web

- `hex`, `srgb`, or `p3` depending on target

### Design / Tooling

- `oklch` or `oklab`

---

## Non-Goals

Serialization never:

- influences semantic decisions
- changes accessibility behavior
- introduces heuristics

---

## Summary

Output configuration is:

- explicit
- orthogonal
- predictable

Palette Kit resolves meaning first.
It formats last.

This document defines the **Output & Serialization Contract** for v0.4.
