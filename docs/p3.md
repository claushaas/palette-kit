# Display-P3

Display-P3 is a wide-gamut color space supported by modern displays and browsers.

## Where P3 works

- **Web**: use `color(display-p3 ...)` in CSS. The library can emit a `@supports` block when `includeP3: true`.
- **React Native / Expo**: P3 string values are not supported as drop-in colors. You can keep the P3 values as data for native APIs on iOS, but sRGB is the safe default.

## How to enable P3

Generate P3 data at source:

```ts
const theme = createTheme({
  neutral: { source: "seed", value: "#111827" },
  accent: { source: "seed", value: "#3d63dd" },
  p3: true,
});
```

### CSS output with P3

```ts
const css = toCssVars(theme, { includeP3: true });
```

### Tailwind output with P3

```ts
const tailwind = toTailwind(theme, { includeP3: true });
```

### JSON/TS output with P3

```ts
const jsonP3 = toJsonWithMode(theme, "p3");
const tsP3 = toTsWithMode(theme, "p3");
```

### Runtime selection helper

```ts
const themeP3 = selectThemeColorMode(theme, "p3");
```

## Fallback strategy

- Prefer sRGB by default.
- Use P3 only when the platform supports it.
